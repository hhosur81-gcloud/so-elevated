Executive Context & Business Drivers
Problem Statement & Objectives
🚨 Current Enterprise Friction
• Fragmented employee experience across WorkWeek (HCM), ServiceImmediately (ITSM), and static policy intranets.
• Heavy Tier-1 HR/IT ticket volume for routine queries (PTO, leave procedures, expense eligibility).
• Manual, disjointed cross-domain workflows (e.g. medical leave, equipment requests).
🎯 The Agentic Vision
• A single conversational entry point with strict policy grounding in Vertex AI Search.
• Real-time, guardrailed self-service across WorkWeek and ServiceImmediately.
• Automated multi-system orchestration with zero-trust origin authentication and forward recovery.
📊 Key Target Metrics (SLA)
• Grounding Precision: ≥95% accuracy, 0% policy hallucinations.
• Safety Overhead: <300ms total latency (<20ms SPII regex masking).
• Security: 100% prompt injection & toxic output interception.
• Origin Provenance: 100% downstream API calls signed with cryptographic JWTs.
• Ticket Deflection: 60%+ reduction in Tier-1 routine HR/IT requests.

Key Decisions: Core Backends & Policy Grounding
Architectural Decision Records
ADR-0001: FastAPI Mock Services
Dedicated Model Context Protocol (MCP) servers for WorkWeek and ServiceImmediately provide realistic stateful enterprise fixtures, type-safe schemas, and built-in guardrails.
ADR-0002 & 0008: Live Vertex AI Search Policy RAG
Connects strictly to live Google Cloud Vertex AI Search datastores holding approved policy documents, enforcing structured citation deep links and zero hallucinations.
ADR-0005: Vertex AI Agent Development Kit
Standardizes on the official Google Cloud Vertex ADK as the core orchestration framework for Gemini model calling, declarative tools, and session state.
ADR-0004: Cross-System Forward Recovery
For multi-step workflows, partial failures (e.g. WorkWeek succeeds, ITSM fails) trigger forward recovery (audit log + sync task + user instructions) rather than rollbacks.

Key Decisions: Zero-Trust Security & Data Protection
Architectural Decision Records
ADR-0003 & 0012: Google Cloud Model Armor Gateway
Multi-stage interceptor executing fast local regex/Presidio pattern matching (<20ms) + targeted LLM prompt injection classifier within <300ms SLA.
ADR-0006: Signed JWT Delegated Authorization
All downstream calls carry a cryptographically signed JWT bearer token containing acting employee identity (sub), automation origin (iss), and scopes.
ADR-0011: Tiered SPII Redaction
Supports legitimate self-service profile queries by displaying unmasked data in ephemeral UI stream, while strictly redacting all SPII from persistent disk logs and audit stores.
FR-1.5: RBAC & Tenant Isolation
Strict employee-scoped session boundaries and token claims ensure users cannot view, query, or modify records belonging to other employees.

Key Decisions: Operational Safety & Session Lifecycle
Architectural Decision Records
ADR-0007: Human Confirmation Gate on Mutations
Requires explicit user confirmation before executing state-changing write operations (Leave of Absence booking, contact updates, ticket status closures).
ADR-0009: Session Expiry & 15m Idle TTL
Dual-trigger session purge: immediately upon user exit prompts ("reset", "clear") or automatically after 15 minutes of inactivity.
ADR-0010: Interactive Priority Guardrail
When a ticket request specifies Priority 1 - Critical without major business outage criteria, interactively prompts user offering Priority 4 - Low.
FR-3.4 & FR-4.3: Real-Time Fetching & Duplicate Guards
Dynamic profile and PTO data fetched live on every query (zero AI caching); rapid successive incident requests scanned for duplicates.

Cross-System Workflow Execution (UC-2.2 Medical Leave)
Sequence & Interaction Flow
🔄 Orchestration Step-by-Step Flow:
  1. Employee Prompt: "I need to take short-term medical leave starting next Monday. Can you set it up?"
  2. Security Sentinel Interceptor: Performs prompt injection scan and toxic language check (<20ms).
  3. Primary Orchestrator (ADK): Identifies composite intent UC-2.2 and calls Policy Q&A Specialist.
  4. Policy Specialist: Retrieves official Medical Leave procedure from Vertex AI Search and returns policy rules + citation link.
  5. Human Confirmation Gate: Orchestrator asks: "Medical leave allows up to 12 weeks. I will submit 5 days starting Aug 24 and open an IT ticket. Should I proceed?" Employee confirms: "Yes".
  6. WorkWeek HCM Specialist: Submits Leave of Absence with signed JWT (Ref #LOA-9081).
  7. ServiceImmediately Specialist: Opens IT ticket to route email to manager during LOA (Ticket INC123456).
  8. Output Interceptor & Response: Tiered SPII redaction on logs; returns grounded confirmation to employee with LOA reference and ticket ID.
